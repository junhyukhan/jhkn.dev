Solution:Pretty straightforward.
```python
class Solution:
    def kidsWithCandies(self, candies: List[int], extraCandies: int) -> List[bool]:
        max_num = max(candies)

        ret = [False] * len(candies)
        for i in range(len(candies)):
            if candies[i] + extraCandies >= max_num:
                ret[i] = True
        return ret
        
```
