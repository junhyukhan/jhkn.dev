Garbage Collection

Types
- Boolean
- Number
- String
- Nil

binary operations
infix and postfix
postfix:
```java
-negateMe;
```
Infix:
```java
add + me;
subtract - me;
multiply * me;
divide / me;
```

No implicit conversion
ie)
```java
123 == "123" // false
```

logical operators
`!`, `and`, `or`
[[control flow constructs in the guise of expressions]]

No bitwise, shift, modulo, or conditional operators.
